# Privacy Policy

This app (yt-render) is a personal, non-commercial automation tool operated by its owner, Abderrahman Medhat. It uploads the owner's own videos to the owner's own YouTube channel using the YouTube Data API (youtube.upload scope).

The app only accesses the Google account of its owner. It does not collect, store, sell, or share any personal data from other users. OAuth tokens are stored only as encrypted secrets in the owner's private GitHub repository and are used solely to upload videos to the owner's channel.

To revoke access at any time, visit https://myaccount.google.com/permissions.
